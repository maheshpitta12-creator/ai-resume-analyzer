# AI-Based Resume Analyzer

An AI-assisted web application that analyzes resumes based on ATS keyword matching and skill detection using React.js and Python.

## Features
- Resume Upload
- ATS Score Simulation
- Skill Keyword Matching
- Resume Analysis Dashboard
- Responsive UI Design
- Real-Time Analysis Workflow

## Technologies Used
- React.js
- Python
- Flask
- JavaScript
- REST APIs

## Project Overview
This application helps users evaluate resumes based on technical skills and ATS keyword matching. It provides resume scoring and analysis visualization through an interactive dashboard.

## Future Improvements
- AI-powered recommendations
- Resume improvement suggestions
- Job-role matching
